# Dan Panorama RTM — reproducible simulation repository

ריפו לשחזור החשבון ולבדיקת מודלי אפס עבור **ממצא דן פנורמה** מ־26–31 ביולי 2026.

## מצב התוצאה

כל 16 הסגירות המוגדרות בקוד עוברות. תחת מודל האירוע המלא:

- הממצא האמיתי: **16/16**;
- 100 מיליון אירועים אקראיים: מקסימום **3/16**;
- לאחר איחוד התלויות לשש משפחות: הממצא **6/6**, והמקסימום ב־100 מיליון אירועים היה **1/6**;
- במעבר ממצה על 810,000 צירופי ערכי מלון–אמיר, רק **435–543** קיבל את הרשת המלאה;
- במבחן חופש חיפוש רחב, צפיפות הרשת הייתה 49 יחסים קצרים, עם זנב מדומה של כ־1 ל־46,087 בריצה הכבדה המצורפת.

המסקנה הנתמכת היא **אנומליה אמפירית מספרית קיצונית ביחס למודלי האפס המוגדרים כאן**. הסימולציות אינן מזהות לבדן מנגנון פיזיקלי ואינן מהוות הוכחה לוגית סופית לחוק טבע מסוים.

## התחלה מהירה

```bash
python -m venv .venv
source .venv/bin/activate       # Windows: .venv\Scripts\activate
pip install -r requirements.txt
make test
make quick
```

הריצה הכבדה:

```bash
make heavy
```

מבחן חופש־החיפוש של מיליון קבוצות הוא החלק האיטי ביותר.

## מבנה הריפו

```text
analysis/                 קוד הסימולציות
 data/case_data.json      נתוני המקרה והנוסחים
 docs/                    מתודולוגיה, פרשנות ורישום מראש
 results/precomputed/     פלטים כבדים קפואים ו־SHA-256
 tests/                   בדיקות יחידה ושחזור
 scripts/                 פקודות quick/heavy
```

## שלוש רמות בדיקה

1. **שחזור:** האם כל ערך וכל משוואה נכונים?
2. **חריגות יחסית למודל:** האם רשת דומה מתקבלת תחת מודל אפס מפורש?
3. **טענה על חוק טבע:** דורשת בנוסף ניסוח מנגנון או כלל מנבא, רישום מראש ושחזור בלתי תלוי.

## נקודות תיעוד שחייבות השלמה לפני פרסום אקדמי

- לצרף את המקור הראשוני לעוגן 58.
- לצרף קבצים או הודעות עם חותמות זמן לנוסח הראשון ולמדידות 30–31 ביולי.
- לצרף תאריך לידה מלא כאשר נטען גיל מדויק ביום מסוים.
- לשמור ולפרסם גם בדיקות שלא נסגרו.
