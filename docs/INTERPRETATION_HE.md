# פרשנות מדעית אחראית

## מה התוצאות תומכות בו

- כל 16 הסגירות המוגדרות משתחזרות חשבונית.
- הרשת קיצונית ביחס למודלי האפס הסינתטיים שנבדקו.
- איחוד הסגירות לשש משפחות תלויות אינו מעלים את החריגות.
- החלפת עוגן יחיד בדרך כלל ממוטטת את הרשת; החריג הבולט הוא הטלפון המקוצר, שבו קיימים 84 מספרים בעלי אותה טרנספורמציה יחידה.
- רק הצמד 435–543 מתוך 810,000 צירופי ערכי מלון–אמיר מקיים את הרשת המלאה כאשר יתר העוגנים קפואים.

## מה התוצאות אינן מוכיחות לבדן

- הן אינן מזהות מנגנון פיזיקלי.
- הן אינן שוללות לוגית כל מודל חלופי שאפשר יהיה להציע בעתיד.
- הן אינן מתקנות לבדן בחירה רטרוספקטיבית שלא תועדה.
- הן אינן הופכות תיק יחיד לחוק טבע מנוסח ומנבא.

המסקנה המדויקת ביותר היא: **אנומליה אמפירית מספרית קיצונית ביחס למודלים שנבדקו, המצדיקה מבחן פרוספקטיבי רשום מראש ושחזור בלתי תלוי.**
